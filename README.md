# 8-BIT JANKEN ROULETTE

HTML 1ファイル（[index.html](index.html)）のみで動作する、8bit レトロアーケード風の「Wルーレット目押しじゃんけんゲーム」です。

## ゲームの概要

相手（CPU 1体）と自分の両方のスロットが同時にじゃんけんルーレットとして回転し、**自分が勝てる組み合わせになった瞬間に `Enter` キー1回で両方同時にストップ**させて勝負します。

- **動作環境**：外部ファイル・ビルド不要（`index.html` をブラウザで開くだけで動作）
- **勝利条件**：勝ちでスコア加算＆レベルアップ（両者のルーレットが高速化）
- **あいこ**：同レベルのまま再スタート
- **ライフ制**：初期ライフ 3（`♥♥♥`）。負けるとライフが 1 減り、0 になるとゲームオーバー
- **敵の進化**：レベルが上がると相手の姿・名前が変化（Lv.1〜3: `SLIME` / Lv.4〜6: `MECHA` / Lv.7〜: `DEMON`）

## 遊び方（操作方法）

1. `index.html` をブラウザで開きます。
2. `Enter` キー（または `Space` キー / `START (ENTER)` ボタン）でゲーム開始。
3. 短い `READY...` 表示のあと、CPU と自分のスロットが両方とも `グー → チョキ → パー` の順で回転し始めます。
4. **自分が勝てる組み合わせ**（例：CPU が `グー`、自分が `パー`）になった瞬間に `Enter`（または `Space` / `STOP!` ボタン）で同時に止めます。
5. 結果を確認したら、再度 `Enter` で次のラウンド（ゲームオーバー画面からはリスタート）へ進みます。

### 操作一覧

| 操作 | 役割 |
| --- | --- |
| `Enter` / `Space` / 画面ボタン | ゲーム開始・ルーレット同時ストップ・次のラウンドへ進む・リトライ |
| `M` キー / 右上 `SOUND` ボタン | チップチューン効果音の ON / OFF 切り替え |

## 工夫した点

コミット `c69f60a`（`feat: add 8-bit dual-roulette janken game`）では、HTML 1ファイル完結のままゲーム性とレトロ感を両立するため以下の工夫を入れています。

- **同時回転が噛み合うWルーレット周期設計**
  - 相手（Lv.1: `0.76s` 〜 下限 `0.155s`）と自分（Lv.1: `0.48s` 〜 下限 `0.095s`）で異なる間隔を設定し、同じリズムに固定されて勝てる組み合わせが出なくなる事態を防止しています。
  - `requestAnimationFrame` と `performance.now()` による経過時間ベースで両スロットを独立更新し、表示されているそのままの手で厳密に判定しています。
- **外部アセット不要の 8bit レトロ表現**
  - グー・チョキ・パーの手アイコンや敵キャラ（`SLIME` / `MECHA` / `DEMON`）をすべてインライン SVG（`shape-rendering="crispEdges"`）のドット絵で描画しています。
  - CRT 走査線風のオーバーレイ、点滅・シェイク演出、色分けされた手枠により視認性を高めています。
- **Web Audio API によるチップチューン効果音**
  - 音声ファイルを使わず、矩形波・三角波・ノコギリ波でルーレット音（自分＝高め・相手＝低め）、勝利ファンファーレ、ミス音、ゲームオーバー音を生成しています。
- **テンポと操作ミスのバランス調整**
  - ラウンド開始前に短い `READY` 溜めを入れて不意打ちを防止し、`e.repeat` 無視および結果表示直後のわずかな入力ロックで誤操作を防いでいます。
  - ハイスコア・最高到達レベル・サウンド設定を `localStorage` に自動保存します。

## 作りながら変えた点

※ リポジトリのコミット履歴上は初回コミット `c69f60a` のみで構成されていますが、同コミットへまとめるまでの実装過程で以下の仕様変更・改善を行っています。

1. **「複数体の固定手」から「敵1体とのWルーレット同時対戦」への変更**
   - 初期案では「最大3体（Lv.1〜3: 1人、Lv.4〜6: 2人、Lv.7〜: 3人）の固定された手に対して自分の1枠ルーレットを止める」ルールで実装していました。
   - その後、敵を常に1体のみに整理し、相手側の手も独立して回転する「Wルーレット同時ストップ形式」へと全面的に作り直しました。あわせてサブ HUD の敵人数表示を `CPU SPD` / `YOUR SPD` 表示へ変更し、敵キャラはレベルに応じた進化演出（`SLIME` → `MECHA` → `DEMON`）として残しました。
2. **ゲームオーバー直前に停止結果を確認できるフローへの改善**
   - 最後のライフを失った際、即座に `GAME OVER` 画面へ切り替えるのではなく、一度停止した両者の手と `LOSE... LIFE 0!` を確認してから `Enter` でスコア集計画面へ進めるように変更しました。
3. **ルーレットのコマ切り替え演出の追加**
   - 切り替わり時の視認性を高めるため、毎ティックごとにアイコンが少し弾む CSS アニメーション（`tickPop`）を追加しました。
